HOW TO ADD YOUR ACHIEVEMENTS
=============================

File to edit:
  src/app/components/achievements/achievements.component.ts

Find this section in the file and replace it with your own data:

-------------------------------------------------------------------

  achievements: Achievement[] = [
    {
      title: 'Your First Achievement Title',
      description: 'Write a short description of what you achieved here.',
      date: 'Jan 2024',
      photos: []   // no photos
    },
    {
      title: 'Your Second Achievement Title',
      description: 'Another description of your achievement.',
      date: 'Mar 2024',
      photos: ['assets/photo1.jpg']   // one photo
    },
    {
      title: 'Your Third Achievement Title',
      description: 'Description of your third achievement.',
      date: 'Jun 2024',
      photos: ['assets/photo2.jpg', 'assets/photo3.jpg']   // multiple photos
    }
  ];

-------------------------------------------------------------------

HOW TO ADD PHOTOS
==================

1. Copy your image files into this folder:
      src/assets/

2. Reference them in the photos array like this:
      photos: ['assets/your-image-name.jpg']

3. You can add as many photos as you want per achievement:
      photos: ['assets/img1.jpg', 'assets/img2.jpg', 'assets/img3.jpg']

4. If you have no photos for an achievement, just leave it empty:
      photos: []


SUPPORTED IMAGE FORMATS
========================
  .jpg  .jpeg  .png  .webp  .gif
